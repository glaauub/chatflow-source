登录信息加密保存在这台电脑。正常关闭或重启不用重填；在后台点击“退出并清除登录”可清除。公用电脑请取消勾选。Token 过期后需要更新。

如何获取 Token？
  1. 打开 GitHub → 头像 → Settings → Developer settings
  2. 选择 Fine-grained tokens → Generate new token
  3. Repository access 选择 Only select repositories，勾选目标仓库
  4. 已有仓库：Contents 设为 Read and write；自动配置网站还需 Pages 写权限及相应管理权限。
  5. 新手建议先在 GitHub 创建空仓库，再选择它授权。自动创建仓库需要 Administration 写权限。
  6. 生成后复制（只显示一次），粘贴到上方输入框
