白帽、灰帽、黑帽：哪些值得做

白帽：真实产品介绍、准确标题、客户问答、正常链接。适合长期经营，先修好下方检查中的问题。

灰帽：批量模板内容、交换链接等。先检查重复标题和空洞内容；付费链接应标明 sponsored，不能当成稳定提排名的方法。

黑帽：隐藏链接、给搜索程序和访客两套内容、批量造假页面。可能带来短期波动，也可能失去搜索曝光。默认关闭隐藏链接输出；需要试验时使用下方开关，不承诺能获客。

高级试验：隐藏链接开关（高风险）

开启后，“板块与页面”中的隐藏链接板块会实际写入网站。关闭后重新生成并发布即可移除。此方法可能损害搜索曝光，不会计为 SEO 优化得分。

记录真实效果：每周花两分钟

从 Google Search Console 复制同一统计口径的数据；询盘填你实际收到的数量。AI 引用要留下问题和来源链接。这里手动记录，不会自动读取账号。

② 经典 SEO 配置（Google / Bing）
先填标题和简介，让客户一眼知道你卖什么。关键词可以后补，堆很多词不会自动提高排名。
填发布后的完整网址，例如 https://www.yourcompany.com。系统用它标明你的正式页面。不要填 localhost 或 127.0.0.1。
旧版“隐藏关键词文字”已被移除——在网页里放看不见的关键词属于黑帽，会被 Google 惩罚。补充关键词保留作选题笔记，不再加入网页代码。站点 Keywords 仅保留兼容用途； meta keywords 与结构化数据，安全合规。
③ 关键词建议器（自动从产品生成）
点击「自动生成推荐关键词」，系统会根据你的产品名 / 分类 / 公司名给出关键词与长尾词（纯本地生成，不联网）。
④ SEO 自检清单（保存并生成网站后再点“开始自检”更准）
逐项检查：标题长度 / 描述长度 / 关键词 / AI GEO / 产品图 alt / sitemap / llms.txt 等，并解释“为什么重要”。
⑤ 推广方法说明
白帽（推荐，长期安全）：
  • 持续产出原创、真实的产品与公司内容；
  • 准确标明产品和公司资料，问答与访客实际看到的内容一致；
  • 页面之间自然内链（产品↔详情↔联系我们）；
  • 图片都写清楚 alt；多语言页面用 hreflang 声明；
  • 在真实行业网站、社媒上做口碑，获取自然外链。
黑帽（危险，有失去搜索曝光的风险）：
  • 关键词堆砌：同一关键词反复塞满页面 → 被判垃圾内容降权；
  • 隐藏文字/链接：白字白底、display:none、看不见的链接 → Google 明确打击；
  • 链接农场/蜘蛛池：批量买卖互链、隐藏外链群 → 可能失去搜索曝光；
  • 伪装页面 Cloaking：给搜索引擎看 A、给用户看 B → 可能违反搜索平台规则；
  • 采集/洗稿：复制他人内容 → 难以提供独特价值。
